lufs-recorder · browser

A zero-install capture primitive. Records audio + MIDI in the browser sandbox, verifies the take honestly, and exports a take.json that shares the native recorder's schema.

Reference UI — the engine is the deliverable. This throwaway front-end exists only to exercise the capture/verify/playback engine (window.LUFSRec) and its data + transport contract. The production surface is a separate design pass (see docs/SURFACE-CONTRACT.md).
